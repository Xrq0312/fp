# Multi-plane and corner optimization plan

## Baseline audit

The preserved baseline is tag `baseline/original`. Its active path is
`src/edge_aware_plane_extract.cpp`:

1. Dense points are collapsed into one fixed 0.5 mm surfel grid.
2. KNN PCA estimates one normal and curvature per surfel.
3. A hard normal jump marks an edge-like surfel.
4. Low-curvature seeds grow greedily through the 26-neighbor graph. A surfel is
   owned by the first accepted patch and is not reconsidered during proposal
   generation.
5. Similar patches are greedily merged. One synchronous boundary pass can
   transfer a surfel only to a label already found in its 26-neighborhood.
6. Dense points are assigned using plane distance, a rectangular 2-D envelope,
   nearby surfel ownership, and optionally the local normal.
7. Corners are generated by enumerating all plane triples and retaining
   intersections with dense and per-plane radius support.

The baseline is strong on dense, clean CAD exports, but has five structural
limitations:

- one spatial/normal scale suppresses fine faces and makes thresholds tied to
  sampling density;
- greedy, exclusive proposal generation makes the result order-dependent;
- the single local competition pass has no model cost or persistent outlier
  label, so it cannot reliably correct over-segmentation and model competition;
- a Boolean edge flag and rectangular support envelope do not describe the
  actual boundary of a face;
- global direction families only relax merging; they do not jointly refine
  parallel or orthogonal planes. Corner enumeration is cubic in patch count and
  does not require three observed pairwise boundaries.

## Fusion architecture

The implementation is staged. Every stage is selectable from the CLI and every
stage includes all earlier stages, so an ablation is a real executable path and
not a reconstruction from Git history.

| Variant | Added mechanism | Main reference idea |
| --- | --- | --- |
| `baseline` | frozen original path | repository baseline |
| `multiscale` | global pass plus adaptive fine residual proposals; deterministic oriented three-surfel hypotheses | CPFN, Efficient RANSAC, Minimal Quadric Fits |
| `joint` | alternating multi-label assignment/refit, label cost, model birth/death/merge | Progressive-X, PEARL |
| `topology` | observed adjacency, one-sided plane support, and conservative dense boundary correction | SED-Net, Progressive-X |
| `boundary` (planned) | continuous multi-scale boundary confidence | SED-Net |
| `--parallel-relations soft|hard` | complete-link parallel relation discovery and centroid-preserving normal refinement; explicit prior only | GlobFit |
| `--corner-mode adjacency` | observed finite intersections, graph-local triples, SVD conditioning, and two-branch support | SED-Net, GCCao validation pattern |
| `--edge-residual-proposals` | unexplained persistent-boundary proposals, model-birth benefit, and local occupied support | CPFN, Progressive-X, SED-Net |
| `--finite-boundary-postprocess` | raw-cloud multi-plane support, segmented pairwise intersections, and synchronous finite-plane competition | finite-support geometry, PEARL-style multi-label competition |
| `--finite-support-region-optimization` | label-independent finite support, connected multi-plane competition regions, and residual/normal-validated synchronous relabeling | finite-support geometry, SED-Net boundary awareness, PEARL-style joint labeling |

The neural components of CPFN and SED-Net are not copied: no training data or
GPU runtime is introduced. Their transferable principles are used instead:
global/local cascades, explicit boundary evidence, and surface-edge feedback.
Likewise, the three-oriented-point and repeated-validation pattern is adapted to
plane proposals; this project does not currently detect cylinders.

## CPU-oriented design

- Dense points are only traversed for voxelization and final assignment.
- Proposal, competition, and relation optimization operate on surfels.
- Spatial neighborhoods use the existing integer grid; no all-pairs graph is
  built.
- Fine-scale work is restricted to unexplained, high-residual, or boundary
  neighborhoods selected by the coarse/global pass.
- Hypotheses are deterministic for reproducibility. Candidate scoring is lazy:
  cheap normal/distance tests precede connectivity and envelope validation.
- Joint labeling uses bounded ICM-style coordinate descent over local candidate
  labels. It implements the PEARL energy terms without adding a graph-cut
  dependency to the CPU build.
- Corner candidates come from triangles in the plane adjacency graph rather
  than all `O(P^3)` triples.
- The dominant large-cloud wall time is PLY parsing/serialization rather than
  joint labeling. `--binary-plane-output` preserves the colored result exactly
  while avoiding tens of seconds of ASCII formatting; ASCII remains the
  compatibility default.

## Raw-geometry finite-boundary postprocess

The optional final postprocess deliberately does not use the current dense
labels as boundary evidence. It has three stages:

1. Every raw point competes against the geometrically plausible final planes.
   A point enters a plane's 2-D occupied support grid only when its best
   normalized residual is below 3, the runner-up is above 3, and their gap is
   at least 1.5. Ambiguous intersection points remain unlabelled.
2. Existing surfel adjacency is used only to propose plane pairs and a finite
   line interval. Raw occupied cells then independently verify, per line bin,
   whether a face terminates or crosses the line. Directed constraints are
   segmented along the line and are valid only inside a local cross-section;
   this is required for concave faces and faces with holes.
3. Every point beyond a verified local boundary competes synchronously against
   all geometrically plausible finite supports. The energy uses the same
   physical scale for the orthogonal plane residual and in-plane distance to
   occupied support. All accepted moves are buffered and applied together, so
   results do not depend on pair traversal order.

Fitted-plane uncertainty and raw-point observation noise are separate. The
former controls intersection location; the latter controls point-to-plane
competition. Missing support never proves a boundary: both faces must provide
near-line raw evidence before a directed segment is created. The current pair
proposal still comes from the surfel adjacency graph, but no existing point
label is used to decide trusted support, termination side, target score, or a
label update.

The option replaces the older topology half-space correction during dense
assignment, while retaining the established local-normal safeguard. This makes
the ablation a true final-stage correction rather than applying the same rule
twice. It remains opt-in pending broader scan ground truth.

## Connected finite-support region optimization

The narrow intersection-band postprocess cannot recover a triangular or
scan-line-connected spill that extends far from the observed line. The optional
`--finite-support-region-optimization` stage therefore runs after dense
assignment and before sparse-patch finalization. It is mutually exclusive with
`--finite-boundary-postprocess`, so each method remains independently
ablatable.

The stage is deliberately label-independent when constructing evidence. It is
an additive final postprocess over the ordinary topology dense assignment; the
postprocess switch no longer changes its own baseline input:

1. Raw points compete against every locally plausible plane by normalized
   residual. Only a unique winner creates an occupied 2-D support cell.
   Multi-plane observations form an uncertainty mask, not positive support for
   every nearby plane. Isolated sampling holes are filled only when bracketed
   in both in-plane directions; concavities and larger holes remain empty.
2. Dense points with unsupported current ownership or a decisive fine-scale
   normal conflict form 0.25 mm spatial nodes. Nodes are keyed by an unordered
   competing-plane pair, not by the current owner. Every candidate label is
   revalidated for every point in the node.
3. Neighbor edges are suppressed across a measured sharp normal change. The
   remaining components use a single-count Potts energy and monotone
   synchronous ICM, eliminating traversal-order changes and label oscillation.
4. The graph proposes a connected relabeling, but cannot override conclusive
   point geometry. A point changes only when the target residual wins by at
   least the joint fitted-noise uncertainty or a confident local PCA normal
   supports the target and rejects the owner. Insufficient evidence retains the
   original label. All accepted destinations are then applied synchronously.

Dense assignment also retains local evidence at sharp boundaries. An edge-like
surfel is allowed to restore its established owner only when the owner wins a
normal/support test, both finite envelopes contain the point tightly, and the
distance loss remains within the two planes' measured fit uncertainty. This
closes the gap between smooth-cell stable ownership and the later connected
region optimizer without expanding the global assignment distance or using
plane-specific exceptions.

An optional `--region-normal-estimator pca-vcm-consensus` mode computes CGAL
VCM normals on the extraction surfel centroids and accepts a normal-only
candidate only when both the fine raw-point PCA estimate and VCM satisfy the
existing smooth-target/sharp-owner tests. Its VCM offset and convolution radii
are derived from `surfel_size`; no dataset-specific threshold is added. The
mode is intended as a conservative evidence cross-check, not a replacement for
fine-scale PCA.

Sub-threshold plane candidates stay available as destinations, allowing raw
support to rescue a small real face. Their outgoing points remain under the
existing all-or-nothing finalizer, which keeps the two ablations separate.
An established plane is also protected from being pushed below the normal
output-support criterion solely by this postprocess.

After relabeling, strict-majority dense ownership is projected back to the
original surfel cells. Mixed cells remain unlabelled. Feature-edge output and
adjacency-based corner extraction consume these final labels, preventing stale
orange edges or stale topology after dense-only corrections. The output plane
CSV records `pre_finalize_plane_id`, so correction CSV ids remain traceable
after sparse candidates are absorbed.

## Evaluation protocol

Two kinds of evidence are kept separate:

1. Deterministic synthetic fixtures provide plane instance labels. The stepped
   box covers small faces, internal openings, and corners; intersecting planes
   with noisy dense edge bands measure boundary spill. Report plane
   precision/recall, macro IoU, coverage, over-segmentation, corner
   precision/recall/error, and runtime.
   A deliberately non-parallel 0.8-degree fixture is a guard against treating
   geometric proximity as proof of a parallel/orthogonal design relation.
2. `top_left_cut` and `top_down` are scan regression datasets without checked-in
   instance ground truth. Report coverage, patch count, fragmentation proxies,
   edge/corner counts, fit RMS, deterministic repeatability, and CPU time; raw
   counts must not be described as accuracy or recall.
3. `top_left_cut2` and `top_down2` are clean CAD samples corresponding to
   `data2.STEP` and `data1.STEP`, respectively. In addition to plane-equation
   checks, extract vertices incident to three distinct STEP planes and use
   one-to-one matching for corner precision, recall, F1, and localization error.
   Coincident but disconnected STEP faces must not be collapsed when future
   plane-instance GT labels are generated. The implemented finite-face evaluator
   parses outer and inner STEP loops (including circular annuli), labels clean
   CAD samples, constructs a prediction/truth IoU matrix, and uses one-to-one
   Hungarian matching to report precision, recall, F1, macro IoU, oversegmentation,
   and undersegmentation.

Acceptance priorities are: (1) no regression in synthetic plane/corner recall,
(2) reduced false merge and fragmentation, (3) higher real-data coverage, and
(4) bounded CPU cost. A stage is not enabled by default until it passes its
ablation against all available datasets.

## Current operator decision

The controlled CGAL comparison found that `Alpha_shape_2` and
`alpha_expansion_graphcut` produced byte-identical labels to the occupied grid
and monotone ICM respectively, while standalone VCM caused substantially more
harmful relabels. Those experimental paths are documented but are not retained
in production code. PCA+VCM consensus is retained because it reduced the
STEP-audited harmful moves from 34 to 1 while preserving 55/55
`top_left_cut2`, 20/20 `top_down2`, corner F1 1.0, stepped_box IoU 1.0,
near_parallel_planes IoU 1.0, and the best crossing_planes IoU 0.985402.

The recommended general pipeline is `topology` plus
`--edge-residual-proposals`. Region optimization remains off by default. When
the application values false-relabel protection over maximum correction
recall, enable `--finite-support-region-optimization` with
`--region-normal-estimator pca-vcm-consensus`. The ordinary PCA mode remains
available for research because it yields slightly higher aggregate IoU but has
lower pointwise correction precision.
