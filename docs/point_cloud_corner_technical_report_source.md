# 点云面片与角点提取技术报告

版本：V1.2  
日期：2026-06-15  
适用数据：以平面结构为主的工件点云

## 1. 项目说明

本项目用于从工件点云中提取平面面片和角点。输入为 PLY 点云文件，程序内部使用 XYZ 坐标完成检测。输出包括两类结果：一类是分割后的平面面片，另一类是多面体角点。

当前代码已封装为 `CornerFeatureDetector`。调用方可以直接传入内存点云，也可以传入 PLY 文件路径。命令行程序只负责解析参数、调用检测器和保存 PLY 结果。

当前交付结果如下。

| 数据 | 面片数 | 角点数 | 输出目录 |
| --- | ---: | ---: | --- |
| `top_left_cut.ply` | 26 | 30 | `best_results/top_left_cut` |
| `top_down.ply` | 17 | 8 | `best_results/top_down` |

## 2. 参考工程

实现过程中参考了以下开源工程的处理思路。参考内容主要用于确定算法路线，并未直接复制其工程代码。

| 工程 | 参考点 | 本项目中的对应处理 |
| --- | --- | --- |
| `xiaohulugo/PointCloudSegmentation` | 局部区域之间按几何相容性进行合并。 | 使用多尺度网格生成局部平面原子，并按法向、距离和空间邻接关系合并。 |
| `abner-math/PlaneDetection` | 平面候选提取、增长、合并和错误平面过滤。 | 保留“候选生成—扩展—合并—过滤”的处理框架，具体实现改为适合当前数据的 atom 方案。 |
| `denabazazian/Edge_Extraction` | 利用局部协方差特征值判断边缘或几何突变。 | 不做全点云边缘检测，只在最终候选角点附近计算协方差分数，用于过滤异常候选。 |

## 3. 总体方案

程序的主体流程分为四步。

1. 预处理点云，估计点云分辨率。
2. 提取平面面片。
3. 根据面片关系生成角点候选。
4. 对候选角点进行合并和过滤。

对应的主要函数调用顺序如下。

```text
prepare_cloud
extract_plane_patches_atoms
expand_patches_per_plane
trim_support_cloud_conflicts
trim_core_cloud_conflicts
filter_weak_visible_patches
extract_corners
```

其中，面片提取是主要步骤。角点基于已提取的平面关系计算，再结合局部点云支持进行筛选。这样可以减少点云边界噪声对角点定位的影响。

## 4. 参数说明

### 4.1 尺度参数的来源

代码中带有 `_scale` 或 `scales` 的参数，大多不是实际距离，而是相对于 `model_resolution` 的倍数。程序运行时会按下面的形式换算：

```text
实际阈值 = 参数值 × model_resolution
```

`atom_cell_scales` 也是同一逻辑。它控制局部平面原子的网格边长：

```text
cell_size = atom_cell_scale × model_resolution
```

这样做的原因是两个数据的点云密度不同。如果直接使用固定距离，同一套参数在密点云和稀点云上会表现不一致。使用 `model_resolution` 归一化后，参数表示的是“多少个点间距”，不是某个固定坐标单位。

推荐值来自当前两组数据的实测调参。`top_left_cut` 使用默认的 `16,32,64`，覆盖更稳定的大面；`top_down` 点云更密、局部碎片更多，推荐改为 `8,16,32`，让局部面片提取更贴近真实几何边界。

### 4.2 主要参数

| 参数 | 含义 | 调整方向 |
| --- | --- | --- |
| `atom_cell_scales` | 局部网格尺度倍数，实际网格边长为 `atom_cell_scale × model_resolution` | 面片过碎时增大；小面漏检时减小。 |
| `atom_max_planarity_error` | 局部平面性阈值 | 误平面多时减小；漏面时增大。 |
| `atom_max_rms_scale` | 局部平面 RMS 残差倍数，实际阈值为 `atom_max_rms_scale × model_resolution` | 误平面多时减小；数据噪声大时增大。 |
| `merge_plane_angle_deg` | 共面合并角度阈值 | 误合并时减小；面片过碎时增大。 |
| `merge_plane_distance_scale` | 共面合并距离倍数 | 误合并时减小；面片过碎时增大。 |
| `merge_plane_adjacency_scale` | 共面合并邻接范围倍数 | 远距离误合并时减小。 |
| `expand_plane_distance_scale` | 面片扩展距离倍数 | 吸点不足时增大；吸入错误区域时减小。 |
| `strict_plane_distance_scale` | 严格内点距离倍数 | 平面被拉偏时减小；点太少时增大。 |
| `support_conflict_scale` | 支持点冲突修剪距离倍数 | 边缘混点多时增大。 |
| `core_conflict_scale` | 核心点冲突修剪距离倍数 | 平面核心不纯时增大。 |
| `corner_support_radius_scale` | 角点支持搜索半径倍数 | 点云密集或角点支持不足时增大。 |
| `min_corner_planes` | 角点最少支持平面数 | 规则三面角建议为 3。 |
| `corner_edge_*` | 边缘辅助过滤参数 | 伪角点多时收紧；真实角点被删时放宽。 |

## 5. 点云预处理

预处理函数为 `prepare_cloud()`。处理内容包括：

- 读取 PLY 点云并转换为 `pcl::PointCloud<pcl::PointXYZ>`。
- 根据坐标范围裁剪数据。
- 估计模型分辨率。

`model_resolution` 是程序内部估计的点云平均采样间距，不需要用户手工填写。计算方式如下：

1. 如果点数不超过 5000，直接使用全部点。
2. 如果点数超过 5000，使用固定随机种子 42 抽取 5000 个点作为代表点。
3. 对代表点建立 KD-Tree。
4. 对每个代表点查找最近的另一个点，记录最近邻距离。
5. 取所有有效最近邻距离的平均值，作为 `model_resolution`。

如果有效点不足导致估计失败，程序使用 `1e-4` 作为兜底值，避免后续阈值为 0。

`model_resolution` 的作用是把“点云密度”转成统一尺度。后续多数距离参数都写成 `scale × model_resolution`，而不是直接写死一个绝对距离。点云更密时，最近邻距离更小，对应阈值自动变小；点云更稀时，阈值自动变大。

## 6. 平面面片提取

### 6.1 局部平面原子

程序先在多个尺度下建立三维网格。每个网格单元中，如果点数达到要求，就对该单元内点集拟合一个局部平面。这个局部平面称为平面原子。

网格尺寸计算方式为：

```text
cell_size = atom_cell_scale × model_resolution
```

例如 `--atom-cell-scales 8,16,32` 表示同时使用三组网格，单元边长分别为 `8 × model_resolution`、`16 × model_resolution` 和 `32 × model_resolution`。这些数不是实际长度，而是相对于当前点云采样间距的倍数。

使用多尺度网格是为了兼顾大面和小面。小网格能保留局部细节，大网格能提高大平面的稳定性。

### 6.2 平面拟合

平面拟合采用 PCA。计算点集协方差矩阵后，最小特征值对应的特征向量作为平面法向。平面方程为：

```text
n · x + d = 0
```

平面性误差定义为：

```text
planarity_error = λmin / (λ1 + λ2 + λ3)
```

该值越小，说明点集越接近平面。

为了降低噪声和边缘混合点影响，程序会进行残差修剪。先拟合初始平面，再保留低残差点重新拟合，重复少量次数。

局部平面原子需要满足两个条件：

- 平面性误差小于 `atom_max_planarity_error`。
- RMS 残差小于 `atom_max_rms_scale × model_resolution`。

### 6.3 原子合并

通过筛选的平面原子只和相邻网格内的原子比较。两个原子满足以下条件时合并：

- 法向夹角足够小。
- 平面距离足够近。
- 网格位置相邻。

合并使用并查集完成。每个连通分量中的点会重新拟合成一个平面候选。

这种处理可以避免把距离很远但数学上共面的区域合并到一起。

### 6.4 面片扩展

局部原子得到的是种子面片，覆盖范围通常不完整。程序会把每个种子面片扩展到完整点云中。

扩展前，先为种子面片建立平面局部坐标系，并记录种子点在该平面上的二维包围盒。完整点云中的点是否属于该面片，由 `point_matches_envelope()` 判断。

判断条件如下。

```text
点到平面的距离 <= expand_plane_distance_scale × model_resolution
点在平面上的投影位于二维包围盒及 margin 范围内
```

第二个条件用于限制扩展范围。如果只使用点到平面的距离，空间上分离的共面区域可能会被错误吸入。

### 6.5 严格重拟合

扩展得到候选点集后，程序会再次拟合平面，并使用更严格的距离阈值筛选核心内点。核心内点用于计算最终平面参数，扩展点集作为支持点保留。

这样可以同时保留较完整的面片范围和较稳定的平面参数。

### 6.6 面片过滤

扩展后的面片还会经过三类过滤。

第一类是形状过滤。短边过小或长宽比过低的面片会被删除。这类面片通常来自边缘条带或噪声区域。

第二类是冲突点修剪。如果某个点同时接近多个非平行平面，或者更接近其他平面，则从当前面片中删除。程序分别处理支持点和核心点，核心点修剪后会重新拟合平面。

第三类是弱面片过滤。程序统计所有面片的可见支持点数和投影密度，并使用中位数构造阈值。支持点太少、密度过低的面片会被删除。

## 7. 角点提取

### 7.1 三平面交点

程序枚举非平行的三平面组合，求解三平面交点：

```text
n1 · x + d1 = 0
n2 · x + d2 = 0
n3 · x + d3 = 0
```

交点需要满足以下条件：

- 三个平面不能退化。
- 交点位于点云整体包围盒附近。
- 交点到三个平面的距离不能过大。
- 交点附近有足够点云支持。
- 每个参与平面在交点附近有足够局部支持。

通过检查后，交点作为候选角点。

### 7.2 面片边界角

三平面交点不能覆盖所有可见角点。对于裁剪、遮挡或缺面导致的边界角，程序会从面片凸包中补充候选。

处理方式为：

1. 将面片点投影到该面片的二维平面。
2. 计算二维凸包。
3. 检查凸包顶点两侧边长。
4. 检查顶点夹角。
5. 检查附近点云支持和面片支持。

满足条件的凸包顶点作为边界角候选。

### 7.3 候选合并

三平面交点和边界角可能互相重复。程序使用 `intersection_merge_scale × model_resolution` 作为半径合并相近候选。

合并时保留支持点更多的位置，并合并其支持平面编号。合并后，如果角点支持的平面数量小于 `min_corner_planes`，则删除。

### 7.4 局部边缘过滤

程序使用 `CornerEdgeScorer` 对候选角点做最后过滤。方法是在候选角点附近取邻域点，计算协方差矩阵特征值，并使用：

```text
edge_score = λmin / (λ1 + λ2 + λ3)
```

作为局部几何变化指标。

该指标用于删除两类候选：

- 局部过于平坦的点。
- 局部过于散乱或大尺度变化异常的点。

这里参考了 `Edge_Extraction` 工程中的局部协方差思想，但只用于候选角点，不对全点云做边缘检测。

## 9. 适用范围和限制

适用场景：

- 工件主要由平面组成。
- 需要输出可解释的平面和角点。
- 点云密度较高，但平面结构清晰。
- 可以针对不同数据设置少量参数。

限制：

- 曲面、圆角、倒角较多时，结果会变差。
- 角点附近缺点严重时，真实角点可能被过滤。
- 超大点云下，逐平面扫描完整点云的耗时仍有优化空间。
- 当前输出是 PLY 点云结果，不包含完整拓扑关系。

## 11. 后续建议

后续如果继续工程化，建议做以下工作：

- 将检测器拆分为头文件和实现文件，形成正式库接口。

## 12. 小结

当前版本围绕平面结构进行角点提取。多尺度平面原子用于得到稳定面片，投影包络用于限制面片扩展范围，冲突点修剪用于提高面片纯度，三平面交点和边界凸包用于生成角点，局部协方差用于过滤异常候选。

该方案在 `top_left_cut.ply` 和 `top_down.ply` 上已经得到稳定结果，可作为当前交付版本。
