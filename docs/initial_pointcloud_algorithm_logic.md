# 最初点云算法逻辑梳理

本文区分仓库中两条容易混淆的“最开始版本”：旧 `main.cpp` 主流程，以及后来单独建立的 edge-aware 流程。提交号用于保证结论可复查。

## 1. 旧 `main.cpp` 的最早仓库基线

对应提交：`7d297f3 chore: establish project baseline`。

这不是简单的 RANSAC 循环，而是“局部平面原子 + 全云扩面 + 冲突裁剪”的流程：

1. 读取 PLY，并可按坐标裁剪输入。
2. 在抽样点上统计最近邻距离，得到模型分辨率；大多数阈值再乘这个分辨率。
3. 用多种 cell scale 把点云划为三维体素，每个体素用 PCA 和残差裁剪拟合局部平面原子。
4. 只检查 26 邻域内的原子；法向接近、平面距离接近时，用并查集合成连通分量。
5. 将每个连通分量重新 robust PCA 拟合为 seed plane，并跨尺度合并法向接近、距离接近、投影包围盒相邻的面。
6. 每个 seed plane 独立扫描全分辨率点云；点面距离和二维 envelope 都满足时纳入候选面，再做严格残差裁剪和重拟合。
7. 再次合并共面面片，并用短边长度、长宽比过滤狭长面片。
8. 对非平行面之间的重叠支持点做冲突裁剪；模糊点会从 support/core 中删除，然后重新拟合。
9. 按可见支持点数量、core 比例和相对密度过滤弱面片。
10. 再扫描一次全云，把 dense 点分配回最终面片。
11. 用三平面交点和单面二维凸包顶点生成角点候选，再以真实邻域支持、多平面支持和多尺度局部协方差过滤。

这条流程的优点是尺度自适应和过滤环节完整；主要问题是参数多、每个 seed 独立扩面，而且冲突处理倾向删掉模糊点，因此点保留率容易下降。狭长面过滤也会把真实窄面和错误条带一起处理，难以满足“错误条带应并回正确大面”的要求。

## 2. 最早的 edge-aware 版本

对应提交：`f3d0244 feat: add edge-aware plane extraction tool`。

流程如下：

1. 读取点云并按 `input_scale` 缩放。
2. 用固定三维网格聚合 dense 点；点数少于 3 的 cell 不生成 surfel。
3. 对整个 surfel cloud 建立 KdTree，一次性执行 KNN 法向估计；每个 surfel 保存局部法向、局部平面偏置和曲率。
4. 可选地从 26 个观察方向做可见性筛选。
5. 遍历每个 surfel 的 26 邻域：
   - 两法向夹角满足 smooth threshold；
   - A 的局部平面能解释 B，B 的局部平面也能解释 A；
   - 满足时用并查集合并；
   - 法向差超过 edge threshold 时将两者标为 edge-like。
6. edge-like surfel 不进入平面连通分量；其余并查集分量按 dense 点数加权 PCA 拟合 PlanePatch。
7. 删除 surfel 数不足、短边过小或长宽比过低的面片。
8. 按面法向、平面偏置和二维 envelope 间距继续合并面片。
9. dense 原始点按点面距离、二维 envelope，以及可选的三维 support-cell halo，分配给最近面。
10. 输出彩色面片、原始 edge surfel 和 CSV 面参数；这一首版尚未提取角点。

这里的“全局法向估计”需要准确理解：程序确实在分割前，对全体 surfel 一次性调用了 NormalEstimation；但每个法向仍是 KNN 局部 PCA 结果，并没有估计全场共享的主方向或法向族。

## 3. 从首版到当前版本的核心变化

当前 `edge_aware_plane_extract` 保留了“全场 surfel 法向先算、dense 点最后回填”的骨架，但有三项根本变化：

1. 并查集组件改为可靠种子驱动的平面区域生长，固定 seed plane 同时约束法向和点面距离。
2. edge-like surfel 可以归属某个面，但不能作为继续跨边生长的节点，减少边缘缺口。
3. 共面合并后增加一次同步边界竞争；候选只来自竞争前的 26 邻域，避免标签逐轮传播穿过大面。

当前仍使用局部 KNN 法向。下一项实验所称“全局法向”特指：先从全场可靠局部法向估计少量/多组稳定方向族，再用方向族正则化可靠 surfel 法向，之后继续执行当前种子生长、合并和边界竞争。它不是再次调用一遍 PCL NormalEstimation。

## 4. 条带问题在两条旧流程中的来源

- 旧 `main.cpp`：各 seed 独立扩面，宽 envelope 可能让一个斜面穿过另一大面；之后用冲突裁剪或狭长面过滤补救，容易丢点。
- 首版 edge-aware：局部并查集合并不可回退；交线附近受混合法向影响的 cell 一旦连接到错误分量，后续只会整体拟合和合并，没有候选面竞争。
- 当前版本：种子面比局部两两连接稳定，且边界可以重新竞争；剩余风险主要来自交线附近 KNN 法向偏转，因此适合测试全局方向族正则化。
